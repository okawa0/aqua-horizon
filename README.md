## **概要**

本サイトは、**実案件をもとにした仮想案件**です。

デザインは既存デザインを用い、**HTML / CSS / JavaScript を用いたフロントエンド実装のみ**を行っています。

---

## **担当範囲**

- コーディング（HTML / CSS / JavaScript）
- レスポンシブ対応
- ハンバーガーメニュー実装

※ **デザイン制作は担当外**とし、デザイン支給で制作しています。

---

## **案件詳細**

- 依頼内容：TOPページのみのコーディング。HTML5+CSS3を使用すること。ブレイクポイントは640px。画像はXDから書き出して使用すること。
- 納期：3日
- 予算：3万円
- 基本要件：ベースのHTMLを元にコーディング。PCのみ表示はvisible-pc、SPのみ表示はvisible-sp。サイドバーの動画は仮でYouTubeの動画を入れること。

## **制作の目的**

- デザインカンプを正確に再現するコーディング力の証明
- 実案件を想定したディレクトリ構成・命名・保守性の確認
- 静的サイトにおける実装力の可視化

---

## **使用技術**

- HTML5
- CSS3
    - BEM記法
- JavaScript（ES6）
    - ハンバーガーメニュー実装

---

## **実装時に意識したポイント**

- JavaScriptをdefer属性で読み込み、DOMの構築を優先
- ナビゲーションメニューとヒーロー画像の位置が逆のデザインを、wrapperで囲みflex-direcrionをcolumn-reverseに指定して対応
- 画像をWebPに変換しパフォーマンス配慮
- ヘッダーとフッターに同じハンバーガーメニューを配置するデザインを、ボタンのaria-controls属性で打ち分けを実現
- ハンバーガーボタンにaria-expandedを付与しアクセシビリティ対応
- バナーはNano Banana Proで生成
- keyframeを用いた無限ループを使用
